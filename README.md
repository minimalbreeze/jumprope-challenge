# 줄넘기 등급 챌린지

초등학생(1~6학년)을 위한 줄넘기 씰 도감 웹앱. 빌드 도구 없는 정적 사이트라서 GitHub Pages에 그대로 올리면 된다.

## 규칙
- 학년별 코스 6개 × 단계 5개 = 씰 30장. 캐릭터는 30장 전부 다르다.
- 씰 배경: 1·2학년 코스 동, 3·4학년 은, 5·6학년 금. 테두리 별 = 단계(1~5).
- 누구나 1학년 코스 1단계부터 시작한다. 앞 단계를 깨야 다음 단계, 한 코스 5장을 다 모아야 다음 학년 코스가 열린다.
- 내 학년보다 높은 코스에서 딴 씰은 반짝이(홀로그램) 씰이 된다.
- 한 학년 코스 씰 5장을 다 모으면 그 학년의 **시크릿 클리어 카드**(6종, 학년마다 색·캐릭터가 다름)가 발급된다.
- 30장(클리어 카드 6장)을 모두 모으면 마지막으로 **마스터 카드**가 발급된다. 카드마다 별명·도감 번호·발급일이 새겨지고, 공유 링크에도 서명과 함께 들어간다.
- 단계: ① 안 걸리고 연속 ② 30초 도전 ③ 연속 2세트(연속 N개를 두 번) ④ 1분 도전 ⑤ 오래 뛰기. 1학년 목표는 7살도 깰 수 있게 낮게 시작한다(연속 3개, 30초 5개, 연속 3개×2, 1분 10개, 10초).
- 미션 숫자는 임시값이다. 실제로 뛰어보고 조정한다 (`js/seals.js`의 `STREAK`·`SPEED30`·`SPEED60`·`ENDURE`).

## 도전 흐름 (AI 코치 자동 판정)
뛰는 아이는 폰을 들지 않는다. 다른 사람이 폰을 들고 찍기만 하면 AI 코치가 자동으로 세고 판정한다.
사람이 누르는 건 START(와 중간에 멈출 때 "그만") 하나뿐이다.

시작 화면 → 퀘스트 창 → (처음 한 번만) 안전 체크 6개·촬영 안내 → 카메라와 AI 코치 준비 → START
→ 아이가 머리부터 발끝까지 보이면 3·2·1 → 자동 측정 → 결과(영상·잘한 점·고칠 점·연습법) → 성공이면 씰.
- 자세 인식: Google MediaPipe Pose Landmarker lite (`js/vendor/mediapipe`, Apache-2.0). 영상은 폰 안에서만 분석한다.
- 점프 세기: 엉덩이가 서 있을 때보다 몸길이(어깨~발목)의 3.5% 이상 올라갔다 내려오면 1개. 1.5초 동안 점프가 없거나 몸이 화면 밖으로 나가면 끊김. (`js/pose.js`)
- 줄 확인: 마이크로 줄이 바닥을 치는 "탁" 소리(1.8kHz 이상의 짧은 소리)를 듣는다. 점프 사이(발이 떨어질 때쯤)에 "탁"이 들린 점프가 60% 이상이면 줄을 넘은 것으로 확신하고, 아니면(잔디·매트, 마이크 거절 등) 성공했을 때만 영상을 보여 주고 어른이 "줄 넘었어요"를 한 번 누른다. 앱이 내는 소리가 나는 동안은 듣지 않는다.
- 탈락: 연속·오래 뛰기는 걸리거나 1.5초 멈추면 바로 탈락. 연속 2세트는 걸린 세트만 다시 세고, 30초·1분 도전은 이어서 센다.
- 움직임: 서 있을 때 높이 기준과 몸 크기를 1~1.5초마다 새로 잡아서, 아이가 앞뒤로 움직여도 따라간다.
- 코치 노트: 끊김, 박자, 높이, 제자리 이동, 팔 벌림, 무릎, 후반 지침을 보고 고칠 점 최대 3개와 연습법을 고른다. 기준값은 초기값이라 실제 영상으로 맞춰야 한다.
- 영상과 코치 노트는 "내 영상"(IndexedDB, `js/clips.js`)에 최근 30개까지 저장한다. 서버로 보내지 않는다.
- 안전 수칙은 처음 한 번만 보여 주고, 도감 관리의 "안전 수칙 다시 보기"로 다시 켤 수 있다.
- 개발용: 주소 뒤에 `?sim=1` 을 붙이면 카메라 대신 가짜 사람 영상으로 확인한다. 콘솔에서 `__simJump = true`(뛰기), `__simRope = true`(줄 돌리기 + "탁" 소리).

## 아이 여러 명
- 한 폰에 아이를 최대 5명까지 등록한다. 시작 화면의 "누가 할래?"나 위쪽 이름표에서 바꾼다.
- 아이마다 씰·카드·마스터 카드·영상·안전 수칙 확인 기록과 **도감 번호(서명 열쇠)**가 따로다.
- 별명은 앞 말 + 뒤 말을 골라 만들거나 직접 쓴다(8자까지). 내 캐릭터 10종 중 하나를 고른다.
- 저장: `jumprope:profiles`. 예전 한 명 기록(`jumprope:state`)은 지우지 않고 첫 아이로 옮겨 쓴다(도감 번호도 그대로).

## 자랑과 주인 확인
- 처음 열 때 기기 안에 서명 열쇠(ECDSA P-256)를 만든다. 비밀 열쇠는 꺼낼 수 없고 서버로 나가지 않는다.
- 공개 열쇠 지문이 도감 번호(예: `#NMVJ-F6UV`)가 된다.
- 자랑 카드: 별명 + 도감 번호 무늬가 카드 전체에 깔리고, QR을 찍으면 서명된 링크가 열린다.
- 링크를 열면 서명을 확인해서 `✔ 진짜 도감` / `⚠ 확인 안 된 도감`(내용을 고친 링크) / `? 주인 확인 불가`를 보여준다.
- 링크를 만든 폰에서 열면 `👑 내 도감` 표시가 추가로 뜬다.

### 한계
- 웹에서는 스크린샷 자체를 막을 수 없다. 대신 캡처한 그림에는 원래 주인 이름과 번호가 따라간다.
- 서버가 없어서, 씰 기록을 진짜로 뛰어서 땄는지까지는 보장하지 못한다.
- 브라우저 데이터를 지우거나 폰을 바꾸면 도감과 열쇠가 같이 사라진다.

## 파일
| 파일 | 내용 |
|---|---|
| `index.html` | 화면과 스타일 |
| `manifest.webmanifest`, `icon-*.png` | 홈 화면 앱 이름("줄넘기 챌린지")과 아이콘. 아이콘을 바꿀 때는 png 4개(180·192·512·512-maskable)를 모두 다시 만든다 |
| `js/seals.js` | 씰 30장 데이터, 미션, 캐릭터·씰·마스터 카드 SVG 그림 |
| `js/identity.js` | 서명 열쇠, 공유 링크 서명·확인 |
| `js/app.js` | 시작 화면, 도감, 씰 받기 연출, 마스터 카드, 자랑 카드, 공유 링크 화면 |
| `js/challenge.js` | 퀘스트 창, 안전 확인, 촬영·자동 판정, 결과 화면 |
| `js/pose.js` | AI 코치: 자세 인식, 점프 세기, 자세 분석과 연습법 |
| `js/clips.js` | 내 영상 보관함 (이 폰에만 저장) |
| `js/vendor/mediapipe/` | MediaPipe Tasks Vision 1.1.0 + pose_landmarker_lite 모델 (Apache-2.0, Google) |
| `js/vendor/qrcode.js` | QR 생성 (qrcode-generator 1.4.4, MIT, Kazuhiko Arase) |

저장 키는 전부 `jumprope:` 접두사를 쓴다.
